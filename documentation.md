# First Order Theory Documentation

## Isabelle's FOL Library

The sketch of Isabelle's FOL library includes:

- Types for variables, implications, and propositions
- Primitive terms for logical connectives and quantifiers
- Terms for variables, constants, lambda abstractions, and applications
- A fixpoint for the type of terms

### Key Definitions and Proofs

- `Types`: Inductive definition of types
- `eqTypes`: Fixpoint for equality of types
- `PT`: Inductive definition of primitive terms
- `PTT`: Fixpoint for the type of primitive terms
- `Terms`: Inductive definition of terms
- `TypeOfTerm`: Fixpoint for the type of terms

## Formalized Theorems and Axioms

Based on the `Isabelle.v` file, the following formalized theorems and axioms are included:

- Inductive definitions for types and primitive terms
- Fixpoints for the type of terms and primitive terms
- Definitions for logical connectives and quantifiers

This documentation provides a summary of the covered axioms and theorems in the FirstOrderTheory repository.
