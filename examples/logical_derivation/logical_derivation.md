# Logical Derivation Example

## Overview
This example demonstrates a complex logical derivation using FirstOrderTheory's framework. The derivation proves that:

> For all x, if P(x) and Q(x) then R(x) implies There exists an x such that R(x)

## Implementations

### Coq Proof
The Coq proof is located in [logical_derivation.v](./logical_derivation.v). It uses classical logic to demonstrate the derivation.

### Python Implementation
The Python implementation is located in [logical_derivation.py](./logical_derivation.py). It provides a practical demonstration of the same logical derivation using Python functions.

## Verification
- The Coq proof can be verified using the repository's verification tools.
- The Python implementation can be tested with pytest.
